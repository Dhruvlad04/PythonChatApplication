# Python Chat Application

## Introduction

This is a simple chat application made using Python socket programming.

The application uses a server and clients to communicate with each other.

## Objective

The main objective of this project is to understand how client-server communication works using Python sockets.

## Technologies Used

- Python
- Socket Programming
- TCP
- Tkinter
- Threading
